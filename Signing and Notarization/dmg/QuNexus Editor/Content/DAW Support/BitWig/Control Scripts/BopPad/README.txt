BopPad Bitwig Template

This folder contains a Bitwig Project, and a controls script for the BopPad. Place the BopPad folder in your Bitwig User Scripts directory in a folder called KMI (you may need to create that folder):

Mac: Documents/Bitwig Studio/Controller Scripts
Windows: %USERPROFILE%\Documents\Bitwig Studio\Controller Scripts\

Then you can open the Bitwig Project. Navigate to the Controllers section of the preferences and Detect Available Controllers, or Add Controller Manually, if that doesn’t work. 

There are four tracks setup, each one is intended to be used with one of the factory presets. Make sure one of the tracks is armed, and if you have the proper preset selected, be able to start making noise. This template is meant to get you started quickly, and show you some of the thing s you can do with BopPad and MIDI Mapping in Bitwig!
