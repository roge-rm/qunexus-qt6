QuNeo MPE

This script provides plug and play operation of the QuNeo MPE using the QuNeo MPE Application. QuNeo MPE is an MPE controller and the per key expression data will be available as pitch bend, Timbre and Press expressions in Bitwig (from the X-Axis, Y-Axis and Z-Axis respectively).

QuNeo MPE Application

You must be running the QuNeo MPE Application with the QuNeo MPE preset loaded. The QuNeo MPE Application translates the QuNeo CC messages into MPE, and you must route MIDI from the app to BitWig using virtual MIDI ports. On MacOS these ports are created automatically by the QuNeo MPE application. This script assumes the names of the ports are "to QuNeo MPE" and "from QuNeo MPE". If you create these ports yourself (on linux or Windows) it is recommended that you use these names.
